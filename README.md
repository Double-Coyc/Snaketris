# Snaketris v0.1.0

**Змейка-Тетрис** — игра, где падающие змейки нужно выстраивать в линии.

## Что нового в этой сборке

- **Точный шаг вбок.** Одиночное нажатие ←/→ (или A/D) сдвигает змейку ровно
  на одну клетку. При удержании включается автоповтор: первый повтор — через
  180 мс, дальше интервал пропорционален скорости падения, поэтому на быстрой
  игре змейка успевает доехать до края поля.
- **Сброс без смены формы.** Пробел или W мгновенно опускает змейку до упора,
  сохраняя ту форму, которая была в момент нажатия: все сегменты едут вниз
  на одно расстояние и не перестраиваются во время падения.
- **Подсветка столбцов.** Под змейкой рисуются полупрозрачные направляющие
  от её сегментов до низа поля — видно, куда она упадёт.

## Как играть

1. Запустите игру двойным кликом на `Snaketris.bat`
2. Введите имя игрока (по умолчанию «Игрок») и нажмите «Сохранить имя»
3. Управляйте змейкой с помощью клавиш:
   - ← → или A D — шаг влево/вправо (удержание — автоповтор)
   - ↓ или S — ускорить падение
   - Пробел или W — мгновенный сброс вниз с сохранением формы
   - P/Esc — пауза
   - R — начать заново
   - 1 2 3 — сложность (лёгкая / обычная / сложная), сразу начинает партию заново

## Правила

- Змейки падают сверху, их нужно выстраивать в линии
- Когда линия полностью заполнена, она исчезает, всё что выше — сдвигается вниз
- За линию начисляются очки: `100 × уровень × 2^(линий − 1)`
- Скорость растёт с каждым уровнем: такт сокращается до 80%, 70% или 60%
  предыдущего в зависимости от сложности
- Игра заканчивается, когда новая змейка не может появиться в зоне спавна

## Таблица лидеров

Справа отображается таблица топ-25: в неё попадает результат каждой партии,
записи сортируются по убыванию счёта. Смена имени в поле «Игрок» не
переписывает прошлые записи, поэтому рекорды разных имён сохраняются.
Данные лежат рядом с игрой в файле `leaderboard.json`.

## Запуск из командной строки

```bash
python.cmd main.py          # обычный запуск
python.cmd main.py --smoke  # проверка без показа окна
```

`python.cmd` — лаунчер, который подставляет путь к портативному Python.
Если Python переедет, путь правится в одном месте — в `python.cmd`.

## Структура проекта

- `app_info.py` — название и версия игры
- `game.py` — правила: поле, падение, фиксация, линии, очки, сложности
- `ui.py` — окно, отрисовка, подсветка столбцов, панель и таблица лидеров
- `keys.py` — таблица управления (работает и на русской раскладке)
- `storage.py` — профиль игрока и таблица лидеров (JSON)
- `main.py` — точка входа и режим `--smoke`
- `Snaketris.bat`, `python.cmd` — запуск двойным кликом
- `test_game.py`, `test_keys.py`, `test_storage.py`, `test_ui.py` — тесты

## Тестирование

Все тесты (включая проверки окна; окно при этом прячется):

```bash
python.cmd -X utf8 -m unittest discover
```

Отдельные наборы:

```bash
python.cmd test_game.py
python.cmd test_keys.py
python.cmd test_storage.py
python.cmd test_ui.py
```

Быстрая проверка запуска без показа окна:

```bash
python.cmd -X utf8 main.py --smoke
```
